# 设计评论家循环深度配置

技术 3（T3）是整套方法的引擎。本文件给出让它稳定收敛的全部配置与常见失败模式。

## 为什么编码代理不能自审

编码代理在同一上下文里记得：自己写的代码、做过的决策、上一轮的修改理由。它无法“跳出来看大图”，评审自己时倾向为既有决策辩护。评论家代理在**全新上下文**中只看到截图，因此能给出真正客观的审美判断。

## 循环结构（每次迭代）

```
编码代理                评论家代理（全新上下文，只收截图）
   │                            │
   ├─ 截图当前设计 ────────────►│ 1. 判断目标美学是什么
   │                            │ 2. 想象顶级工作室会如何执行
   │◄──────── 反馈 + 评分/10 ────│ 3. 列出最大差距
   ├─ 按反馈修改                │ 4. 打分（独立、客观）
   └─ 重复直到评分 ≥9/10        │
```

- 每轮都用**同一评论家 prompt**，评分标准才可比。
- “≥9/10 才算完成”只存在于编码代理的 prompt 中，**绝不写进评论家 prompt**——评论家必须保持客观，否则会自我修正评分、循环失真。
- 截图是唯一输入。给代码、实现细节或历史迭代都会污染判断。

## 评论家标准的客观性分级

| 级别 | 写法 | 效果 |
|---|---|---|
| ❌ Bad | “Judge if our design looks beautiful, not AI-generated.” | 太主观，结果逐轮飘忽 |
| ⚠️ OK | “Review the aesthetic we're going for, visualize how a top design studio would execute it, then judge our design's quality against that bar.” | 仍偏模糊，但给了统一框架与质量参照 |
| ✅ Great | “Here are 5 designs: 4 professional examples and 1 screenshot of our product. Rank them by polish and taste level.” | 具体、客观，有视觉基线，结果稳定 |

选择顺序：能用 Great 就用 Great；没有范例图片时退回 OK。

## 质量基线（moodboard）用法

- 给评论家提供 2-4 张代表目标水准的图片：可比产品截图、你欣赏的设计、或 AI 概念图。
- 明确要求把这些图当作**基线/moodboard，而非复制目标**——防止评论家引导代理直接抄。
- 基线越接近你真正想要的品味，评论家给出的差距越准。

## 停止条件与 token 防护

- **默认先跑 1-2 轮**，观察评分是否收敛（连续两轮评分不再上升即收敛）。
- 收敛后再决定是否追加轮次；不收敛时优先调整评论家 prompt（更客观），而不是无限加轮。
- 无停止条件的循环 = 评论家永不满意 = 代理疯狂烧 token。这条防护必须由执行代理的 prompt 承载。

## 模型分工与 token 经济学

| 角色 | 模型选择 | 理由 |
|---|---|---|
| 评论家 | 大模型（参数越多越好） | 更好的设计品味、更宽的想法分布 |
| 执行代理 | 便宜但“能胜任执行”的模型 | 干重复苦活；太小则执行不好方向 |

- 评论家只做“执行级决策”，原文实测其输出 token 占比 **<10%**。
- 反例警示：让评论家模型直接重做页面——成本翻倍、耗时更长、且失去了客观评审视角。

## 常见失败模式

1. **评论家永不满意** → 无停止条件或标准太主观。加收敛检查、换成 Great 级标准。
2. **评论家太宽松** → 评分虚高、无实质提升。换更强模型、给更严的质量基线。
3. **执行代理“作弊”**（把代码/理由塞给评论家）→ 评审失去客观性。在循环 prompt 里显式禁止传递非截图信息。
4. **每轮评论家 prompt 不一致** → 评分不可比、循环震荡。锁定同一 prompt 文本。
5. **评论家直接抄基线图** → 把 moodboard 明确标注为“基准而非目标”。

## 实测参考数据

- 原文（Claude Opus 5 执行 + Claude Fable 5 评论）在 4 组设计上均达到 ≥9/10，且每组仍保持各自的高层美学方向不变——**评论家提升执行细节，不改变设计身份**。这是循环正常工作的标志：如果身份漂移，说明评论家 prompt 越权了（它在指导方向而非评审执行）。
